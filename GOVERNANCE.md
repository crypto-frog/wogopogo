# Governance

Wogopogo uses a maintainer-led, contribution-friendly model.

Maintainers set project direction, review changes, manage releases, operate the hosted service, and protect its users. Contributors influence direction through issues, discussions, testing, documentation, and pull requests.

Decisions are guided by:

1. Community usefulness in the Okanagan Valley
2. Privacy and security
3. Accessibility
4. Operational simplicity
5. Long-term maintainability
6. Search accuracy without manipulative practices

A contribution may be technically sound and still be declined when it creates disproportionate moderation, infrastructure, legal, or maintenance obligations. Maintainers will explain material scope decisions when practical.

The hosted service and the open-source repository have separate release processes. Repository access does not grant production access, and merged code is deployed only after maintainer-controlled review and verification.
