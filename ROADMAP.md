# Roadmap

The roadmap communicates direction, not a delivery promise. Priorities are evaluated against community value, privacy, accessibility, security, and the operational limits of shared hosting.

## Current priorities

### Reliability and maintainability

- Expand backend contract and migration tests
- Improve release packaging and upgrade verification
- Document recovery exercises for files and database backups
- Continue dependency and supported-runtime maintenance

### Accessibility

- Add repeatable automated accessibility checks
- Continue keyboard, zoom, contrast, and screen-reader reviews
- Improve validation guidance without increasing form friction

### Community usefulness

- Improve job-category stewardship and documentation
- Explore privacy-conscious job expiry reminders
- Evaluate a carefully moderated employer information layer
- Make local deployment and contribution onboarding easier

### Search quality

- Continue validating JobPosting structured data
- Improve sitemap and expired-listing monitoring
- Preserve useful public HTML without creating thin or repetitive pages

## Ideas requiring discussion

The following are not committed features:

- Optional email digests
- Automated featured-listing payments
- Multiple moderator roles
- Public APIs or feeds
- Localization beyond the current Canadian English interface
- Alternative hosting adapters

Open a feature proposal before implementing a roadmap item. Large additions need a clear operating model, abuse analysis, and maintenance plan.
