# Support

## Questions and setup help

Use [GitHub Discussions](https://github.com/crypto-frog/wogopogo/discussions) for installation questions, design discussion, and contributor guidance. Search existing material first and include the relevant runtime versions, operating system, and non-sensitive error details.

## Bugs

Open a bug report with reproducible steps, expected behaviour, actual behaviour, and the smallest safe diagnostic output needed to understand the problem.

## Security

Do not use issues or discussions for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Hosted service

The public repository documents and develops the software. It does not promise support, uptime, moderation outcomes, or deployment of every merged contribution to `wogopogo.ca`.
